# Мой инфраструктурный стенд

Учусь работать с Linux и Git на тестовой виртуальной машине.

Этот сервер содержит NGINX

## Обратный прокси Nginx

Прокси принимает запрос к /health на порту 8081 и передаёт
его сервису на порту 8080 той же ВМ.

Проверка: curl -i http://127.0.0.1:8081/health
Ожидаемый результат: HTTP 200 и тело ok.
